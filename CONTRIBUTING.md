# Contributing

## Настройка development окружения

Перед тем, как приступать к работе над проектом, необходимо настроить
окружение. Для этого необходимо для начала установить следующие зависимости:

- NodeJS версии `24.15.0`
- `npm` версии `11.12.1`

Эти зависимости можно установить из [официального сайта NodeJS](https://nodejs.org/en/download)

Далее, необходимо установить все зависимости путем ввода следующей команды

```shell
npm install
```

## Запуск проекта в dev режиме

Для отладки приложения в dev режиме необходимо запустить его через следующую команду

```shell
npm run dev
```

После ввода команды приложение будет доступно через `localhost`.
