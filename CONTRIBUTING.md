# Contributing

## Настройка development окружения

Перед тем, как приступать к работе над проектом, необходимо настроить
окружение. Для этого необходимо для начала установить следующие зависимости:

- NodeJS версии `24.15.0`
- `npm` версии `11.12.1`

Эти зависимости можно установить из [официального сайта NodeJS](https://nodejs.org/en/download)

Далее, необходимо установить все зависимости путем ввода следующей команды

```shell
npm install
```

## Запуск проекта в dev режиме

1. Перед запуском проекта убедитесь, что запущен бэкенд. Больше подробностей
   по запуску бэкенда можно найти в репозитории [`wb-landing-builder`](https://github.com/rki-mai/wb-landing-builder)

2. Убедитесь, что бэкенд доступен по адресу `http://localhost:8080`

3. Настройте окружение проекта, указав следующее содержимое в `.env` файле

   ```env
   VITE_ACCESS_KEY="<access-key>"
   VITE_PROJECT_ID="<project-id>"
   ```

   где `VITE_ACCESS_KEY` - JWT-токен для авторизации на бэкенде, а `VITE_PROJECT_ID` - ID проекта,
   который будем редактировать.

4. Запустите проект через следующую команду

   ```shell
   npm run dev
   ```

   После ввода команды приложение будет доступно через `localhost`.
